# Pascal-projects

A collection of Pascal programming projects ranging from beginner to advanced levels.

## Structure

- **beginner/** – Simple programs introducing basic syntax, variables, input/output, and control structures
- **intermediate/** – Programs covering arrays, records, procedures/functions, and file handling
- **advanced/** – More complex programs including algorithms, data structures, and modular design

## How to compile and run

You can compile these programs using Free Pascal Compiler (`fpc`):

```bash
fpc filename.pas
./filename
```

Or use any modern Pascal compiler (Delphi, Lazarus, etc.).

Happy coding!

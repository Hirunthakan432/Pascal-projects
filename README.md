# Pascal-projects

A collection of Pascal programs from beginner to advanced, plus modular units and mini-projects.

## Repository structure

```
Pascal-projects/
├── beginner/       # 25 programs (basics → mini-projects)
├── intermediate/   # 24 programs (arrays, records, algorithms → apps)
├── advanced/       # 25 programs (algorithms, data structures → systems)
└── modules/        # Reusable units with demos (~10 files per topic)
```

## Modules (`modules/`)

Each subfolder holds a reusable **unit** plus demos and helpers (~10 files each):

| Folder | Focus |
|--------|--------|
| `mathutils/` | Arithmetic, power, factorial, GCD, primes |
| `stringutils/` | Reverse, palindrome, trim, word count, replace |
| `arrayutils/` | Fill, sort, search, reverse |
| `dateutils/` | Leap year, validation, day-of-year, age |
| `stackunit/` | Stack ops, parentheses check, two-stacks |
| `queueunit/` | Circular queue, priority queue, deque |
| `geometry/` | Circle, rectangle, triangle, sphere, Heron |
| `fileutils/` | Write, read, copy, append |
| `statistics/` | Mean, variance, median, mode, range |
| `conversion/` | Temperature, length, weight, speed, area |
| `complex/` | Complex arithmetic, conjugate, powers of *i* |

See `modules/README.md` for compilation notes on units.

## How to compile and run

**Free Pascal Compiler:**

```bash
fpc filename.pas
./filename
```

**Modules (example):**

```bash
cd modules/mathutils
fpc mathutils.pas
fpc demo_mathutils.pas
./demo_mathutils
```

Also works with **Lazarus** and **Delphi** (most examples use standard Pascal features).
